# Bug: Brain 'agentic' not found in registry

## Bug
`⚠️ Failed to create brain 'agentic': Brain 'agentic' not found in registry. Available: ['muzero']`
The AI Player failed to instantiate the `agentic` brain and fell back to `RandomSolver`.

## Cause
The brain registration system relies on Python modules being imported to trigger the `@Registry.register_brain` decorators. In `src/autogameplayer/runner/cli.py`, the `agentic_brain` and several other brain/solver modules were not being imported, so they were never registered in the global `Registry`.

## Solution
Updated the import section of `src/autogameplayer/runner/cli.py` to explicitly import all relevant brain and solver modules (including `agentic_brain`, `random_brain`, `walk_brain`, `llm_brain`, `muzero.brain`, and various new solvers like `SkillSolver` and `RouterSolver`). Used `# noqa: F401` to prevent linters from removing these side-effect imports.

## Test
Confirmed that `brain: "agentic"` is now correctly found in the registry during startup and successfully instantiated.
