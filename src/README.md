# Source Directory 🏗️

The core Python packages for AutoGamePlayer.

### Modules
- `brains/`: Specialized AI agents (Agentic, Multi-Agent Orchestration).
- `core/`: Fundamental interfaces, configuration, and environment logic.
- `emulators/`: Wrappers for PyBoy and mGBA.
- `server/`: The MCP Server and WebSocket streaming engine.
- `utils/`: LLM clients, image processing, and shared helpers.
- `vision/`: DINOv2-based perception and image annotation.
- `runner/`: CLI entry points.
